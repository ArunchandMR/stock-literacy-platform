What This Platform Does

Watchlist Dashboard

Tracks a manually curated set of NSE stocks with live prices, entry, target, and stop-loss. Auto-updated daily via GitHub Actions.

Swing Squeeze Scanner

Scans 500+ NSE tickers daily for EMA 20/50 compression + RSI 30–55 + volume dry-up. BRD-aligned. Flags Critical / Setup / Watch levels.

Box / Fortress Scanner

Detects range breakout setups where price is near 60-day box ceiling with EMA compressed. Shows GTT entry, stop-loss, and R:R.

Core Study Principles

Rules I follow for every setup considered

Only surplus capital

Never allocate money needed for expenses, EMIs, or emergencies.

Always use a stop-loss

Every trade has a defined exit. No position is held without a stop below entry.

No leverage or F&O

Cash equity only. Derivatives amplify losses and are not part of this study scope.

Rule-based entries only

No tips, no social media. Every entry must satisfy the BRD scanner criteria before consideration.
