How to Execute This Strategy

1. NSE Stock Selection

Filter for Advances → sort by Total Volume → pick 5%+ movers. These are your momentum candidates already in active uptrends.

2. Box Setup on Chart

Open daily chart. Draw horizontal rectangle between swing high and swing low with ≥20% range. Breakout above upper band = entry signal.

3. GTT Order (Stress-Free)

Place limit order just above box high after breakout candle closes. It fires automatically on retest. No intraday monitoring needed.

4. Profit Targets

50% of box height = conservative partial booking. 100% clone of the box = full swing target. Pure price symmetry — mathematically objective.

5. Stop Loss

Hard stop at box low. Use small allocation per trade (e.g. ₹5,000) so a full loss never damages overall portfolio.

6. Capital Allocation

Split into small pots. Deploy only a fraction per breakout. Equity only — never leverage or F&O with this strategy.

Advantages: Mathematically objective targets, stress-free GTT execution, no time decay (equity only), predefined risk per trade.
Risks: Capital locked 40–100+ days; wide nominal drawdowns before the move fires. Only use surplus funds you can afford to hold.
